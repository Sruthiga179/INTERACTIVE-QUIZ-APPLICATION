Introduction

This is a simple and interactive Quiz Application built using HTML, CSS, and JavaScript. The application presents a series of multiple-choice questions to users and provides instant feedback on their answers. The quiz keeps track of the user's score and displays the final results at the end. The user has the option to retry the quiz or close the application.

Features

Loading Screen: A countdown timer (3 seconds) before the quiz starts, adding a suspenseful effect.

Dynamic Question Display: Questions are displayed one at a time, and options are dynamically generated.

Instant Feedback: Users receive immediate feedback after selecting an option (correct/incorrect).

Next Question Button: Appears only after selecting an answer.

Final Score Display: At the end of the quiz, the user's score is shown along with retry and exit options.

Responsive Design: Works well on different screen sizes.

Smooth UI Animations: Interactive buttons with hover effects and color transitions.

Technologies Used

HTML5: Structure of the quiz application.

CSS3: Styling, animations, and responsiveness.

JavaScript (Vanilla JS): Core logic to handle quiz functionality.

How It Works

Loading Screen

When the user opens the quiz, a loading screen with a countdown timer (3 seconds) is displayed.

After the countdown, the quiz starts automatically.

Question Display

The application loads questions dynamically from a predefined array.

Each question has four options, and users can click one option to select their answer.

Answer Selection & Feedback

When a user selects an answer:

If correct, the button turns green and the feedback message says "🎉 Correct!".

If incorrect, the button turns red and the feedback message says "❌ Incorrect!".

All options are disabled to prevent multiple selections.

The "Next Question" button appears.

Navigating Through Questions

Clicking the "Next Question" button loads the next question.

The quiz continues until all 10 questions are answered.

Displaying Results

After the last question, the quiz container hides, and the result container is displayed.

The final score is shown in the format Your Score: X/10.

Two buttons are provided:

Reattempt Quiz: Reloads the quiz from the beginning.

Close Quiz: Closes the window.

Code Overview

HTML:

Contains three main sections: Loading Screen, Quiz Container, and Result Container.

CSS:

Styles the quiz with a dark theme, rounded buttons, and hover effects.

JavaScript:

Defines the list of quiz questions in an array.

Implements logic for displaying questions, checking answers, and updating the UI.

Manages quiz progression and displays results at the end.
